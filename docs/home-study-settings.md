# 首页入口与今日学习设置

2026-09-06，延续 Quiet Growth 视觉，修改原有知练项目。

## 产品行为

- 首页只展示今日学习和自由学习两张卡片，移除最近学习和模块长列表。搜索移至自由学习页面。
- 自由学习：左侧切换言语模块、数量关系、资料分析、常识理论，右侧显示对应分类，点击进入原有分组学习。
- 今日学习：卡片展示所选分类/词库、每日新学目标、实际剩余复习/新学/练习数量；“学习设置”进入独立页面。
- 设置支持真实学习分类，成语另可选全部、原有高频词库 153 条、800 词补充 735 条；每日新学可选 5/10/20 个。
- 所选范围内先复习最多 10 个，再新学，最后最多 5 道配套题；不足时按实际数量安排。自由学习不会改变选定分类，不再跨分类补足今日任务。
- 未开始的当天计划随设置立即更新；已开始或完成时，保留任务、断点和结果，新设置次日生效。设置页和首页明确提示生效时机。退出未保存不改变偏好。

## 存储与同步

学习偏好复用 V4 事件队列，新增 preferences 事件和计划设置快照。按事件时间合并，已开始的计划不会被另一设备的新设置清空。服务端明确返回 learningSettingsVersion=1 后，客户端才确认设置相关事件；旧版本不会错误丢弃待同步设置。基础计划最多 35 项，本轮重练仍最多 10 项。静态题库、稳定 ID 和原有学习统计不变。

## 验证

Validation: L3。60 项相关测试通过，包括新增 7 项学习设置/导航测试、1 项旧服务端确认保护测试、1 项服务端偏好与 20 条任务集成测试；原有学习闭环、账户、同步与存储测试继续通过。56 个 JavaScript 文件和全部小程序 JSON 检查通过；后续提示文案修改单独复查语法及相关测试。

微信开发者工具原工程、iPhone 12/13 Pro 宽度：两张首页卡片可直接看到；自由学习左右布局及真实分类显示正常；设置页显示分类、词库范围和 5/10/20 数量，已开始用户显示次日生效提示。保存、取消、当天替换、跨日、断点及跨设备合并由自动化测试验证。

当前开发者工具报 API 域名不在 request 合法域名列表，属于在线同步环境问题，未修改用户私有配置绕过校验。生产后端尚未部署此次学习设置能力，发布前须随 V4 服务端和共享模型一并升级；不能将本机接口测试视为生产同步验收。
