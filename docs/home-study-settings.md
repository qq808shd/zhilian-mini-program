# 首页入口与今日学习设置

2026-09-06，延续 Quiet Growth 视觉，修改原有知练项目。

## 产品行为

- 首页只展示今日学习和自由学习两张淡绿色卡片；顶部标签与设置按钮垂直居中，卡内留白、按钮高度和卡间距一致。自由学习下一页按左侧模块、右侧分类进入，保留搜索。
- 今日学习只选择模块、分类及每日新学数量。上传批次不再作为范围选项，静态题库的来源、原有顺序、分组和稳定 ID 保留。
- 数量滑动条位于设置页首张卡，模块与分类选择放在下方；额外复习与配套题通过“新学之外，还有哪些安排？”解释，明确固定上限及与新学数量的关系。
- 数量使用原生整数滑动条，范围为 1 至 min(200, 分类知识总量)。成语 888 条最多选择 200；三字词 113 条最右端为“全部 113 个”；诗词 2 条最右端为“全部 2 个”。切换到小分类时自动收缩数值，不保存就不改变偏好。
- 所选分类内先复习最多 10 个，再新学，最后最多 5 道配套题；剩余未学内容不足时按实际数量安排。自由学习不会改变今日学习分类，不跨分类补足任务。普通专项练习与测验仍最多 20 题。
- 未开始的当天计划随设置立即更新；已开始或完成时保留任务、断点和结果，新设置次日生效。
- 四个 Tab 共用底部组件，48px 操作区、24px 图标、11px 标签；系统手势安全区单独保留，页面预留底部空间。通过真实路由更新选中态，切换失败不假装跳转成功。

## 存储与同步

学习设置 version 2 使用 V4 持久事件队列；旧批次偏好只迁移一次，完整保留已开始的当天计划。默认未开始的旧计划重新按全分类生成。

服务端返回 learningSettingsVersion=2 后，客户端才确认设置相关事件；旧服务端不能错误丢弃待同步设置。服务端继续接收历史 5/10/20 与批次事件，协议 2 的数量校验为整数 1–200 且不允许批次设置。基础计划最多 215 项，本轮重练最多 10 项，总计不超过 225；每批上传仍最多 200 个事件，重传幂等。

## 验证

Validation: L3。67 项相关测试通过，覆盖整数数量、分类上限、200 个新学加复习/练习/重练的完整 225 项流程、旧设置迁移与断点、两批进度上传、旧服务端确认保护、用户隔离、普通考试 20 题限制和四项导航切换。57 个 JavaScript 文件及全部小程序 JSON 检查通过，diff 无空白格式错误。

微信开发者工具原工程、iPhone 12/13 Pro 预览已检查：首页两张卡片、四个 Tab 的图标与选中态、成语拖至 200、三字词拖至全部 113、诗词自动收缩到全部 2、设置页滚动与固定保存按钮。退出未保存后首页原 10 个设置保持不变。

生产后端尚未部署此次数量设置能力；发布前须随 V4 服务端和共享模型一并升级。开发者工具现有 API 域名校验错误未绕过；本机接口测试不等同于生产同步验收。
