# 知练视觉系统：Quiet Growth

> 更新时间：2026-09-05。适用原生微信小程序全部页面。在原 Calm Focus 基础上重构，以当前用户确认的淡绿色方向为准。

## 设计原则

正式但不严肃，专业但不冰冷。主次来自排版、留白与操作顺序。暖白背景、白色内容面、低饱和绿主色。一个阶段一个主要动作；模块和分类卡接近容器全宽，首页辅助入口用较轻的行式布局。

不使用大面积渐变、玻璃拟态、厚重阴影、装饰性大图或 emoji 图标。不添加不存在的业务与统计。

## 文字与空间

- 中文系统字体，不加载网络字体。
- 页面标题 39–46rpx；知识标题 48–54rpx；题干 34rpx、行高至少 1.65。
- 模块标题 30–34rpx；正文 27–30rpx；辅助信息通常 23–26rpx。
- 数字使用稳定宽度与清晰单位，正确率无记录时显示“—”。
- 间距 8/16/24/32/40/48/64rpx；页面左右默认 32rpx，学习卡 24rpx。
- 圆角：标签 12rpx、控件 16rpx、卡片 24rpx、学习卡 28rpx。
- 阴影仅弱区分内容面：常规 0 8rpx 24rpx rgba(40,53,44,.025)，学习卡 .045。

## 共享组件

- ui-entry：全宽可点击列表，标题、说明、数据、状态、箭头顺序固定。用于模块/分类，支持单字科目标识。
- progress-meter：原生进度组件集中桥接颜色，进度必须配可读文本；不靠动态内联宽度。
- ui-state：短标题、原因、一个恢复动作；用于空列表和不存在的学习内容。
- math-formula：继续使用真实分式、根式和幂；长公式允许局部横向滚动，页面不横向溢出。
- 全局 primary-button / secondary-button / text-button：主绿底白字、次白底绿边、文字型低强调。按钮高度通常 92–96rpx，禁用有实际 disabled 状态。
- card / metrics / actions-row / stack / pill：统一内容面、数字与状态布局。

## 状态语义

| 状态 | 表达 | 依据 |
| --- | --- | --- |
| 未开始 | 尚未练习、无正确率 | 无作答记录 |
| 学习中 | 已浏览 n / total | 既有分组最远位置 |
| 已浏览完 | 可重新学习、练习这一组 | 已到最后一条，不宣称掌握 |
| 待复习 | 待复习 | activeWrong |
| 巩固中 | 已答对 1 次，再巩固一次 | activeWrong + consecutiveCorrect=1 |
| 已巩固 | 连续答对 2 次 | 曾答错且已移出 activeWrong |
| 正确/错误 | ✓/×、答案文字、柔和底色 | 实际选项与正确答案 |

禁止只用颜色传递状态。确认后的练习答案锁定；测验交卷前不显示正确答案。浏览解析不更改掌握状态。

## 页面与路径

- 首页首先续学，没有记录则推荐原有高频成语；练习与复习为轻入口。
- 模块/分类显示帮助做决定的浏览进度与错题情况；不堆数据。
- 分组保留资料顺序和来源批次；有分类练习入口。
- 学习卡占主要可用高度，正文独立滚动，底部导航留安全区。完成后可练本组。
- 答题页减少装饰；题号、实际用时、答题卡、题干、选项、确认/下一题顺序明确。
- 练习逐题解析；专项测验交卷后解析，明确不是整套模拟卷。
- 结果先本次正确率与用时，再下一步建议，最后逐题解析/错题筛选。
- 复习按薄弱分类、高频错点、实际题目逐层展开；支持待复习/已巩固与常错/最近排序。

## 适配与动效

系统导航保留微信胶囊安全区域；三个原生 Tab。正文不被底部操作遮挡，底部留 env(safe-area-inset-bottom)。小屏、长题干、长选项与长解析自然换行。正常卡片滑动 260ms，按压反馈 120–160ms，不用循环动画；CSS 动效尊重 reduced-motion。

仅采用浅色视觉，不声明已实现深色主题。真实图片/表格题暂不存在，不引入空壳模板。题库本地读取即时展示，不制造假 loading 或骨架屏；网络错误沿用本地优先业务逻辑。
