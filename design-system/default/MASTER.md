# 知练视觉系统：Quiet Growth

> 更新时间：2026-09-07。适用原生微信小程序全部页面。在原 Calm Focus 基础上重构，以当前用户确认的淡绿色方向为准。

## 设计原则

正式但不严肃，专业但不冰冷。主次来自排版、留白与操作顺序。暖白背景、白色内容面、低饱和绿主色。让用户直接选择学习行为；模块和分类卡接近容器全宽，首页通过范围卡与并列新学／复习区区分层级。

不使用大面积渐变、玻璃拟态、厚重阴影、装饰性大图或 emoji 图标。不添加不存在的业务与统计。

## 文字与空间

- 中文系统字体，不加载网络字体。
- 页面标题 39–46rpx；知识标题 48–54rpx；题干 34rpx、行高至少 1.65。
- 模块标题 30–34rpx；正文 27–30rpx；辅助信息通常 23–26rpx。
- 数字使用稳定宽度与清晰单位，正确率无记录时显示“—”。
- 间距 8/16/24/32/40/48/64rpx；页面左右默认 32rpx，学习卡 24rpx。
- 圆角：标签 12rpx、控件 16rpx、卡片 24rpx、学习卡 28rpx。
- 阴影仅弱区分内容面：常规 0 8rpx 24rpx rgba(40,53,44,.025)，学习卡 .045。

## 共享组件

- ui-entry：全宽可点击列表，标题、说明、数据、状态、箭头顺序固定。用于模块/分类，支持单字科目标识。
- progress-meter：原生进度组件集中桥接颜色，进度必须配可读文本；不靠动态内联宽度。
- ui-state：短标题、原因、一个恢复动作；用于空列表和不存在的学习内容。
- math-formula：继续使用真实分式、根式和幂；长公式允许局部横向滚动，页面不横向溢出。
- 全局 primary-button / secondary-button / text-button：主绿底白字、次白底绿边、文字型低强调。按钮高度通常 92–96rpx，禁用有实际 disabled 状态。
- 学习程度使用 `styles/learning-controls.wxss` 的三等分紧凑控件，64px 高，22px 图标在上、14px 标签在下。必须显式覆盖微信按钮默认宽度，使用 Flex、`width:0`、`min-width:0`；三个标签均完整显示。三档按钮统一白底，不显示默认选中态；释义隐藏时也可直接标记。卡内查看入口为可选操作。
- card / metrics / actions-row / stack / pill：统一内容面、数字与状态布局。

## 状态语义

| 状态 | 表达 | 依据 |
| --- | --- | --- |
| 未学习 | 陌生 · 未学习 | 没有正式学习标记，默认程度不计入已学分布 |
| 已学习 | 已学习 n / total | 首次主动选择任一程度；重复标记不重复计数 |
| 陌生／了解／掌握 | 用户当前选择的程度 | 与已学习进度独立，三个程度都参与自动复习 |
| 熟知 | 熟知 · 已免复习 | 用户经确认明确退出，可再次点击星标恢复 |
| 本组学完 | 学习下一组 / 返回学习范围；可自由练习 | 本组全部正式学习，不强制配套题 |
| 今日待复习 | 实际到期数量 | 已学习、未免复习且达到算法日期，当天已学不重复安排 |
| 下次复习 | 下次复习日期 | FSRS-6 默认模型与实际记录推导，不再展示固定阶段 |
| 正确/错误 | ✓/×、答案文字、柔和底色 | 实际选项与正确答案，独立保留题目统计 |

禁止只用颜色传递状态。确认后的练习答案锁定；测验交卷前不显示正确答案。浏览解析不更改程度；只有主动标记才保存。“掌握”和“到期”可以同时存在，时间推移不自动降低程度。

## 页面与路径

- 首页上部为学习范围卡、切换入口和已学进度，下方显示程度数量；学习区并列新学、复习及实际数量，练习统一从底部“练习”Tab 进入，首页不重复放置入口。自由分类阅读和搜索继续可达。
- 模块/分类区分已学习进度、当前程度与到期数量；不把已掌握解释为不再复习，不堆无关数据。
- 分组保留资料顺序和来源批次；有分类练习入口。
- 学习卡占主要可用高度，正文独立滚动；新学先隐藏释义与解析，点击后揭示，也可不展开直接评分；复习同样允许直接回忆评分。底部固定陌生／了解／掌握，保存后自动继续并留安全区；左右滑动回看；熟知星标直接打开居中确认弹窗。完成后可主动自由练习。
- 答题页减少装饰；题号、实际用时、答题卡、题干、选项、确认/下一题顺序明确。
- 练习逐题解析；专项测验交卷后解析，明确不是整套模拟卷。
- 结果先本次正确率与用时，再下一步建议，最后逐题解析/错题筛选。
- 复习优先展示当前范围的到期数量和进入按钮；知识记录可按分类及程度查找，不再用阶段检验任务链增加层级。主动错题练习保留。

## 适配与动效

系统导航保留微信胶囊安全区域；学习／练习／小组／我的四项共享自定义 TabBar，48px 操作区与底部手势安全区分别计算，图标 24px、标签 11px。正文不被底部操作遮挡，底部留 env(safe-area-inset-bottom)。小屏、长题干、长选项与长解析自然换行。正常卡片滑动 260ms，按压反馈 120–160ms，不用循环动画；CSS 动效尊重 reduced-motion。

仅采用浅色视觉，不声明已实现深色主题。真实图片/表格题暂不存在，不引入空壳模板。题库本地读取即时展示，不制造假 loading 或骨架屏；网络错误沿用本地优先业务逻辑。

V5 新学与复习在同一学习区并列，复用原有色彩和卡片语言；学习进度、程度与到期状态分别表达。规则与实现状态见 [V5 学习与复习](../../docs/v5-learning.md)。

## Image 2 V3 实施规格

当前首页、学习和个人中心遵循 [V3 设计与尺寸板](references/learning-v3-spec.png)及[生成提示词](references/learning-v3-prompt.txt)，替代第二版单一绿色控件。设置沿用同一组颜色、间距与圆角。以原生字体和微信导航安全区落地，插画保留第二版书页嫩芽，运行时为压缩 JPEG；图标为可缩放 SVG。

- 390px 参考屏宽，页面左右各 20px；卡片宽随屏幕减 40px，圆角 20px，区块间距 12px。
- 页面/范围主标题 22px、区域标题 18px、知识标题 30px、正文 16px/28px、辅助标签 13px。中文使用系统字体。
- 程度按钮等宽，间距 12px、高 64px、圆角 16px。三个按钮均白底、同样细边和轻阴影；22px 图标分别使用琥珀、蓝、绿，不根据当前程度渲染选中背景。仅保存过渡、确认弹窗或熟知免复习时禁用。
- 背景 #F8F7F3、正文 #303D36、品牌绿 #4D785B、浅鼠尾草 #EDF3E8；蓝 #527FAD / #ECF3FA，琥珀 #B57A32 / #FBF1DF，珊瑚 #B56859 / #FAEEE9。绿色负责品牌、新学与进度，蓝色用于复习、查看和联系，琥珀用于陌生和熟知，珊瑚用于自由练习及删除。
- 首页切换入口紧邻范围标题，不加白底胶囊，不换行；插画独立占右侧区域。四种程度统计在统一白色面板内。
- 学习进度显示“当前位置 / 总数”，下方为 6px 高、3px 圆角进度条。无“新学”位置标签，无上一条文字按钮；左右滑动不评分。
- 熟知为金色星标＋文字，点击区至少 44px。直接显示微信居中确认弹窗，明确免自动复习和可恢复，不经过动作菜单。
- 我的页面移除页内重复标题与同步卡；邮箱使用蓝色信封图标，完整显示 386305161@qq.com。自动同步逻辑不依赖手动入口。
- 学习设置继承首页当前范围，保留数量、清空及保存。清空仅影响当前范围的学习记录，先居中确认；不在设置页重选模块。
