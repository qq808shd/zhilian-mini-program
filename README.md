# 知练小程序

个人使用的知识学习、客观题测试和错题复习微信小程序。

## 打开方式

1. 启动微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择当前文件夹。
4. 确认 AppID 为 `wx8cd28fbd80c4b941`。
5. 点击“编译”。

目前使用本地知识库和本地存储，答题后即可在“复习”页看到错题与分类正确率。

“言语模块”现包含 888 条成语，以及从 Word 资料整理的 113 条三字词与常用表达。成语由原有 153 条词库与“成语800词”照片资料增量合并而成：照片资料实际含 839 个编号，其中 4 条不是四字词、1 条标题重复、99 条与现有词库重合，最终净新增 735 条。合并按名称去重，现有词条的释义、顺序和统计 ID 均保持不变。学习分组按资料批次断开：第 1—8 组只包含原有 153 条高频词，第 9—45 组按照片原编号顺序排列 735 条补充词，不会在同一组混入两批资料。成语和三字词均按每组最多 20 条学习，可单独组卷考试；分组页还提供“全部查看与搜索”，用于按词语或释义快速查阅，大词库采用分批加载以控制页面渲染量。

“资料分析”模块首期包含增长率、增长量、比重、平均数、倍数与比值、混合增长、贡献与拉动 7 个分类，共 25 张公式卡和 50 道客观题。统计口径参考国家统计局，衍生公式均从基础定义分步推导。
