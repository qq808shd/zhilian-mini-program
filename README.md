## 学习体验与界面

界面延续 Quiet Growth 暖白与淡绿色。首页按学习范围和学习区组织；新学与复习分别进入，不再自动串接配套题或本轮再练。自由分类阅读、搜索、专项练习和测验仍可独立使用。

- 新学按所选分类的原有资料顺序安排，每日数量为 1 至 min(200, 分类总量)，默认 10；剩余不足按实际数量，不跨分类补足。保存范围或数量立即生效，保留当天已经完成的记录。
- 学习进度与程度独立。新学先隐藏释义与解析，可点击查看，也可直接选择程度；底部陌生／了解／掌握任一标记都计为已学习，保存后自动前进；回看、查阅和单纯展开解析不会隐式完成。重复标记不重复增加进度。
- 复习可直接根据回忆标记程度，查看解析为可选操作。三种程度都参与 FSRS-6 调度，每条知识根据时间和历史反馈安排日期；当天完成后不再自动重复安排，不再使用固定 1／3／7 天阶段。
- FSRS-6 当前采用公开默认参数和 90% 目标回忆概率，尚未进行个人参数拟合；它提供记忆估计和复习安排，不声称测量个人的真实遗忘率。
- 熟知通过星标直接打开居中弹窗确认，表示退出自动复习，可主动取消恢复；不表示永久不会遗忘，旧 V4 已掌握也不会被自动改成熟知。
- 新学和复习分别按北京时间日期、模式及分类保存会话；完成后可返回学习或自主选择练习，没有必经配套题。普通专项练习与测验每轮仍最多 20 题。
- V5 保留旧学习记录、自评、阅读位置、当天已完成内容和待上传事件；“清空答题记录”保留正式学习、主动程度和熟知决定。近七日正确率只使用真实作答，不把自评或旧聚合统计伪造成成绩。
- 题库仍为 1044 条知识、1089 道题，成语 888 条及既有分组顺序未变。

实现、算法依据、迁移及本轮验证状态见 [V5 学习与复习](docs/v5-learning.md)。[V4 学习闭环](docs/v4/learning-loop.md)保留历史缘由与当时验证；历史视觉改造见 [UI / UX 重构](docs/ui-ux-refactor.md)，当前规则见 [Design System](design-system/default/MASTER.md)。
