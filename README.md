# 知练小程序

正式名称为“知练个人笔记”，是一款面向本人及朋友使用的知识学习、客观题测试和错题复习微信小程序。

## 打开方式

1. 启动微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择当前文件夹。
4. 确认 AppID 为 `wx01e13d3df486356c`。
5. 点击“编译”。

目前使用本地知识库和本地存储，答题后即可在“复习”页看到错题与分类正确率。

## 云同步

项目已经加入“题库本地、用户数据云端”的同步能力：

- 成语、三字词、公式、题目和解析继续随小程序打包，离线仍可学习和考试；
- 学习进度、答题统计和错题状态先写本机，再批量同步到阿里云轻量应用服务器；
- 使用微信 OpenID 区分用户，不需要自建用户名和密码；
- 首次连接会导入本机已有记录，后续用唯一答题事件增量同步，网络重试不会重复计数；
- 云端暂时不可用时不会阻断学习，待网络恢复后自动重试。

生产同步服务已部署在阿里云北京地域轻量应用服务器，使用 `https://api.dabaommz.cloud` 提供 HTTPS 接口；域名备案号为“辽ICP备2026020036号-1”。Nginx 与 `zhilian-api` 已启用，`miniprogram/config/cloud.js` 已开启生产连接。2026-09-03 已通过真实微信登录验证首次基线导入和重复编译幂等：本地 10 次作答、9 道当前错题及学习进度成功同步，重复连接未重复计数。轻量 Node.js + SQLite 服务端位于 `server/`，完整部署说明见 `server/README.md`。AppSecret、会话密钥、数据库和 `.env` 不得提交到 GitHub。

“言语模块”现包含 888 条成语，以及从 Word 资料整理的 113 条三字词与常用表达。成语由原有 153 条词库与“成语800词”照片资料增量合并而成：照片资料实际含 839 个编号，其中 4 条不是四字词、1 条标题重复、99 条与现有词库重合，最终净新增 735 条。合并按名称去重，现有词条的释义、顺序和统计 ID 均保持不变。学习分组按资料批次断开：第 1—8 组只包含原有 153 条高频词，第 9—45 组按照片原编号顺序排列 735 条补充词，不会在同一组混入两批资料。成语和三字词均按每组最多 20 条学习，可单独组卷考试；分组页还提供“全部查看与搜索”，用于按词语或释义快速查阅，大词库采用分批加载以控制页面渲染量。

“资料分析”模块首期包含增长率、增长量、比重、平均数、倍数与比值、混合增长、贡献与拉动 7 个分类，共 25 张公式卡和 50 道客观题。统计口径参考国家统计局，衍生公式均从基础定义分步推导。

## 学习体验与界面

界面采用 Quiet Growth 淡绿色设计系统，底部为“学习 / 练习 / 复习 / 我的”。首页可继续上次阅读；学完一组后可直接练习相关题目。练习支持逐题确认解析，专项测验支持答题卡、标记和交卷后反馈，每次最多 20 题。结果可重练错题或回到专项学习。错题支持常错/最近排序、待复习/已巩固筛选，连续答对两次后移出待复习。

精确阅读位置保存在当前设备；云端仍使用原有最远学习进度。累计正确率与浏览进度分别显示，不虚构打卡、趋势或整套模拟卷。设计规范见 [Design System](design-system/default/MASTER.md)，功能盘点与重构说明见 [UI / UX 重构](docs/ui-ux-refactor.md)。

## 我的与首次使用

首次欢迎页使用 Image 2 生成的书页嫩芽插画；用户先阅读并同意协议，随后自动登录并在后台同步学习记录，不需要另开同步开关；暂不同意时仍可本机学习。首次同意后可通过微信原生控件快捷填写头像、昵称，也可跳过；头像昵称仅保存在本机，后续从“我的”修改。OpenID 继续由既有微信登录服务识别，不另建密码账号。

“我的”提供真实学习概览、学习记录、同步状态、设置、帮助与反馈、关于、协议及备案入口。同步页只显示真实状态，失败时可重试；断网时保留记录，恢复网络后自动补传；清空答题记录仍保留学习进度并生成云端重置指令。

运营主体、联系邮箱、小程序备案号和生效日期待补齐，集中在 `miniprogram/config/product.js`。当前协议为开发草稿：开发版和体验版可以体验同步，正式版资料未齐时只开放本机学习。上线前还需完善 `miniprogram/data/legal.js` 正文、微信后台隐私指引、备案查询跳转，并用真实微信验证头像昵称能力；仅复制查询网址不代表备案跳转已验收。详细设计与实现见 [我的与首次使用](docs/designs/account-onboarding/README.md)。
